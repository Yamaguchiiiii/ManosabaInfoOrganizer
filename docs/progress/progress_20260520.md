## プロジェクト概要

ゲーム「魔法少女の魔女裁判」のプレイ支援ツール。  
推理整理・キャラクターノート・行動ルート可視化を一体化したデスクトップ + ブラウザ対応アプリ。

**技術スタック:** React 19 + TypeScript + Vite + Zustand + Konva.js + SCSS + Tauri 2 (Rust)  
**状態永続化:** IndexedDB（Zustand persist ミドルウェア経由）  
**重要規約（CLAUDE.md）:**
- UIコンポーネントから `@tauri-apps/api` / `localStorage` / `window.showOpenFilePicker` を**直接呼ばない**
- プラットフォーム分岐は `src/services/` または `src/adapters/` に集約（`window.__TAURI__` で判定）
- `any` 型の使用禁止
- カスタム Hook でビジネスロジックと UI を分離
- モバイルファースト・レスポンシブ設計

#### 機能5: Esc キーでツール解除
- **修正ファイル:** `src/components/NoteView.tsx`
- **問題:** `handleKeyDown` で `if (e.target !== document.body) return` ガードが Esc チェックより前にあったため、ツールバーボタンにフォーカスが残っている状態で Esc を押しても無視されていた
- **修正:** Esc チェックをガード判定より前に移動

  ```typescript
  const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
          setPlacementMode(null);
          return;
      }
      if (e.target !== document.body) return;
      // ...
  };
  ```

- **補足:** テキスト編集中の Esc は textarea の `onKeyDown` 内で `e.currentTarget.blur()` + `e.stopPropagation()` により処理されるため、window リスナーには到達しない（重複処理なし）

### 【セッション11】resolve_error/9.md の作成と実装（`_symptoms.md #05/20_19:00` 対応）

#### 問題分析・設計（`docs/resolve_error/9.md` 作成）

**問題1: 複雑なSync操作でタイミングがずれる**

根本原因を3点特定：
- **原因A（最重要）:** `handleSyncTime` と `syncTarget useEffect` 内の `duration` 計算が `Math.max(displayPath.length * 30, 60)`（ノード数ベースの近似値）を使用しており、`store.ts` の `computeDuration()`（ピクセル距離ベース）と食い違っていた。`calculateNodeArrivalTime` は `startTime + duration * (distToTarget / totalDist)` を使うため、`duration` の誤りが到達時刻のズレに直結する。
- **原因B:** `syncTarget` state が単一オブジェクトのため、2回目の Sync で1回目の制約が上書きされる
- **原因C:** Sync 制約が UI に表示されないため、ユーザーが状態を確認できない

**問題2: Sync UI が複雑な操作に対応できない**

根本原因: `syncTarget`（単一）と `WaypointPanel`（Sync 情報を表示しない）の設計では、複数地点の Sync 制約を管理・表示できない。

---

#### 問題2対応: `SyncConstraint` 管理 UI の追加

**`src/components/create/WaypointPanel.tsx`**
- `SyncConstraint` インターフェースを export 追加（`CreateView` からインポートする方向で循環参照を回避）
  ```typescript
  export interface SyncConstraint {
      waypointId: string;
      waypointName: string;
      meetingTime: number;
      charIds: string[];
  }
  ```
- Props に `syncConstraints: SyncConstraint[]` / `onRemoveSyncConstraint: (index: number) => void` を追加
- `+ Add Stop` ボタン直下に Sync Constraints 表示 UI を追加
  - 最後の制約（active）を黄色ハイライト表示
  - 各行に `×` 削除ボタン
  - 地点名はテキストオーバーフロー `ellipsis` で `maxWidth: 300px` に収める

**`src/components/CreateView.tsx`**
- `SyncConstraint` を `WaypointPanel` から import
- `syncConstraints: SyncConstraint[]` state を追加
- `primaryIcon` 切り替え時のリセットに `setSyncConstraints([])` を追加
- `handleEditPath` に `setSyncConstraints([]); setSyncTarget(null);` を追加（Edit ボタン押下時のリセット）
- `handleMergeConfirm` に upsert ロジックを追加（同一 `waypointId` なら上書き、新規なら追加）
- `handleRemoveSyncConstraint` ハンドラを追加（active 制約削除時は `syncTarget` も更新）
- `WaypointPanel` JSX に `syncConstraints` / `onRemoveSyncConstraint` を受け渡し

#### 問題1対応: `duration` 計算の修正

**`src/store.ts`**
