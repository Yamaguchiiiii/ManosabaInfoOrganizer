## プロジェクト概要

ゲーム「魔法少女の魔女裁判」のプレイ支援ツール。
推理整理・キャラクターノート・行動ルート可視化を一体化したデスクトップ + ブラウザ対応アプリ。

**技術スタック:** React + TypeScript + Vite + Zustand + Konva.js + SCSS + Tauri (Rust)
**状態永続化:** IndexedDB（Zustand persist ミドルウェア経由）
**重要規約（CLAUDE.md）:** プラットフォーム直呼び禁止（`src/services`/`src/adapters` に集約）/ `any` 禁止 / Hook で UI とロジック分離 / モバイルファースト。
