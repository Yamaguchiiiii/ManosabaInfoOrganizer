## プロジェクト概要

ゲーム「魔法少女の魔女裁判」のプレイ支援ツール。  
推理整理・キャラクターノート・行動ルート可視化を一体化したデスクトップ + ブラウザ対応アプリ。

**技術スタック:** React 19 + TypeScript + Vite + Zustand + Konva.js + SCSS + Tauri 2 (Rust)  
**状態永続化:** IndexedDB（Zustand persist ミドルウェア経由）  
**重要規約（CLAUDE.md）:**
- UIコンポーネントから `@tauri-apps/api` / `localStorage` / `window.showOpenFilePicker` を**直接呼ばない**
- プラットフォーム分岐は `src/services/` または `src/adapters/` に集約（`window.__TAURI__` で判定）
- `any` 型の使用禁止
- カスタム Hook でビジネスロジックと UI を分離
- モバイルファースト・レスポンシブ設計

### 【セッション8】resolve_error/7.md の実装（`_symptoms.md #05/16_22:00` 対応）

#### 問題1: テキストをクリックしてもバウンディングボックスが表示されない
- **修正:** Transformer useEffect のフィルタを単独/複数で分岐
  - 複数選択: Text を除外（スケール変形防止）
  - 単独選択: Text も含める（バウンディングボックス表示のため）
- テキスト単独選択時は `enabledAnchors={[]}`, `rotateEnabled={false}` で選択枠のみ表示

#### 問題2: Text+他オブジェクトのグループ化が視覚的に見えない
- **修正:** 複数選択時に選択中テキストオブジェクトへカスタム選択インジケーター `<Rect>` を描画
  - `stroke="#007acc"`, `dash`, `listening={false}` で Transformer 外の選択表示を補完

#### 問題3: デフォルトキャラクター画像のパスと配置位置
- **修正:** `./icon/${selectedChar}` → `./character/${selectedChar}` に変更
- `maxDimension` 500 → 800 に拡大
- 配置位置を `x:0, y: 600 - height/2`（左下に上半身が見える）に変更

#### 問題4: Undo 挙動の根本修正
- **修正:** `debouncedSaveHistory`（変更後保存）を廃止し `saveHistoryOnceThenSkip` に変更
- バッチ先頭の変更前に1回だけ `saveNoteHistory()` を呼び、300ms 以内の後続変更では保存をスキップ
- これにより「S0→S1→S2」の推移で Ctrl+Z が S1→S0 と正しく段階的に戻る

#### 問題5: フリーライティング補正の強さをスライダーに変更
- **修正:** compact pad・char-sidebar 両方の `<select>` を `<input type="range" min="0" max="5">` に変更

#### 問題6: ○・△のドラッグ配置位置がクリック開始点になる
- **修正:** `handleStageMouseUp` の isDrag ケースで circle/triangle の場合のみ `x + dragW/2`, `y + dragH/2` で中心座標に補正

#### 問題2: グループ化テキストオブジェクトがドラッグ時に移動しない
- **修正ファイル:** `src/components/NoteView.tsx`
- `URLImage` / `EditableText` / `ShapeObject` に `onDragMove` / `onDragEnd` prop を追加
- `groupDragHandlers` を実装:
  - `onDragMove`: ストア座標を基準に delta を計算し、グループ他メンバーの Konva ノードを直接移動
  - `onDragEnd`: `updateNoteObjects` で全グループメンバーをバッチ更新

#### 問題3・4: キャンバス論理座標系の統一 + ズームでサイズ変化しない
- **修正ファイル:** `src/components/NoteView.tsx`
- compact/非compact 問わず `CANVAS_BASE_WIDTH=1200`, `CANVAS_BASE_HEIGHT=800` を共通定数として定義
- `scale = Math.min(stageWidth / 1200, stageHeight / 800, 1)` に統一
- NotesPanel（compact）と NoteView（非compact）で同一論理座標系を共有
- ブラウザズームによる CSS ピクセル変化は scale が吸収し、論理座標は不変

#### 問題5: 透明背景画像の自動クロップ
- **修正ファイル:** `src/components/NoteView.tsx`
- `autocropTransparent()` 関数を追加（Canvas API で alpha > 10 のピクセルの min/max 検出）
- `processFile()` をこれを呼ぶ形に変更（ファイル読込 → クロップ → base64 返却）
- クロップ後の画像が asset として保存されるため、透明余白を含むバウンディングボックスを防止

#### 問題6: 画像のアスペクト比ロック（デフォルト ON）
- **修正ファイル:** `src/store.ts`, `src/components/NoteView.tsx`
- `NoteObject` に `keepRatio?: boolean` フィールドを追加
- 全画像追加箇所（handleDrop・handleStageMouseUp isDrag/click・デフォルトキャラ初期化）に `keepRatio: true` を設定
- Transformer の `keepRatio` 条件に `image && (keepRatio ?? true)` を追加
- char-sidebar と compact pad に「アスペクト比を維持」チェックボックス UI を追加
