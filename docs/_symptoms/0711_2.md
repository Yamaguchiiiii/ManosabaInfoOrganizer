# 改善したい点

1. Noteページでノートの折り畳みバーを折りたたむと，Canvasに空白(グレー)が表示されてしまう．また，この状態で4ペイン表示にしてもグレーを含むCanvasが4面に表示される
2. スマホ表示場合のみ，Animateページの事件ノートCanvas上でオブジェクトを選択した際に表示される「1個選択|レイヤー...」といったオプションは，事件ノートの折り畳みボタンの横に表示して，現在のオブジェクト選択時にピコピコとオプションを表示するためのバーを表示と非表示を繰り返すのをやめて
3. スマホ表示の際にチュートリアルが機能していない部分があるので，スマホ表示でも機能するようにして．
4. スマホ表示の際にAnimateでsyncや会話イベントをクリックしたら，そのイベントが発生した時間だけでなく，そのイベントが発生したマップを表示するようにする
5. CanvasをPNGとして書き出す際には，Canvas背景の点線グリッドも背景として設定したまま書き出して．
