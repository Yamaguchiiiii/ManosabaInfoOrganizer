# 希望機能：

## Create関係
1. Createページで行動を作成したキャラクターに対してhあ，サイドバーのICONSの対応するキャラアイコン表示を「すでに行動を作成し終えている」ことがわかるよう工夫する（e.g. キャラアイコンの表示を暗くして緑色のチェックマークをICONの上に載せるなど）
2. Createページでキャラクターの行動経路を作成時に，中継地点を指定した際にSyncができるようになっているのはいいが，syncを行う時計アイコンが出てしまいUIが乱れるので，時計アイコンや中継地点を削除するバツアイコンを表示する際は，中継地点名のボックスの幅を必要分減らして，SとGの幅と同じになるようにする

## Note 関係
3. Notes ページのToolsのフリーライティング機能で，手振れ補正機能を追加したい．
4. Notes ページのToolsのフリーライティング機能で，手振れ機能補正の強さや色，線幅，線の種類を変えられるようにしたい
5. Notes ページのToolsを一度クリックして機能を選択している際に，escキーを押すと選択を解除できるようにしたい．
6. Notes ページの雑多ページで作成したノートページ名を編集する際は，alert的な処理ではなく，アプリおよびサイト内で完結するモダンな処理にしたい．
7. Notes ページのキャンバスで，配置されたオブジェクトのグループ化（ショートカットキー：ctrl+G），グループ化解除（ctrl+shift+G）を行えるようにしたい
8. Notes ページのキャンバスで，選択中のオブジェクトのレイヤーの移動（最前面に移動，再平面に移動など，より良い実装方法があればそれを行ってもよい）を行えるようにしたい．
9. Notes ページのキャンバスで，図形や画像を追加する際，単にクリックされた場合は現在の実装のようにそのまま配置してよいが，ドラッグされた場合には，大きさをドラッグされているマウスポインタの位置まで拡大を行い，ドラッグが終了した際に図形オブジェクトとして確定させる．
10. Notes ページのキャンバスで，図形やテキストをドラッグして拡大・縮小する際，図形の枠線やテキストのサイズが変化しないようにする．
11. Notes ページのキャンバスで，図形やテキストをドラッグして拡大・縮小する際，図形の枠線やテキストのサイズが変化しないようにする．
12. Notes ページのキャンバスで，テキスト内容を編集する際には（現在のようにテキストボックスが広がる形ではなく）Powerpointのように現在のテキストボックスの領域を保ったまま編集できるようにする．その際，そのままのテキストボックス領域だと領域外にはみ出る文字がある場合は自動でテキストボックスの大きさを適切に広げる．
13. Notes ページのキャンバスで，配置されたテキストを編集する際に現在トップバーにsizeやboldを出しているが，それをやめてpowerpointのようにオーバーレイ？フローティングフィンウィンドウ？が表示されてそこから編集を行えるようにしたい．
