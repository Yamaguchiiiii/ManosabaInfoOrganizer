## 症状1: 複数Syncで最初のSyncがずれる ✅（要動作確認）

### 根本原因（推定）

到達時刻計算 `calculateNodeArrivalTime` が `path.indexOf(targetNodeId)`、すなわち
**地点の「最初の出現」固定**で時刻を求めていた（`resolve_error/10.md` の症状3で
「残存制限」として明記済みの箇所）。

同一地点を複数回訪れる経路や、Sync後に経路を伸ばす複雑なSyncでは、アンカー
（1回目Syncの基準地点）の到達時刻が**意図と異なるオカレンス**で再計算され、
`syncTarget` 追従 useEffect が `startTime` を再算出するたびに自分のタイムライン全体が
ずれ、結果として最初のSyncの合流タイミングがずれて見える。

### 修正

オカレンス（経路上の何番目の訪問か＝pathIndex）を指定して到達時刻を求められるようにした。

- `utils/animationUtils.ts`
  - `calculateArrivalTimeAtIndex(charData, targetIndex, allNodes)` を新規追加。
    path のインデックスで距離を積算し、id→node フィルタによる
    インデックスずれも起きないように実装（従来の `calculateNodeArrivalTime` の
    潜在バグも解消）。
  - `calculateNodeArrivalTime` は `indexOf` で index を求め上記へ委譲する薄いラッパに変更
    （従来挙動＝最初の出現は維持）。
- `components/CreateView.tsx`
  - `syncTarget` に `pathIndex?` を追加。Sync状態 `myCurrentSyncPathIndex` を保持。
  - `handleSyncTime(id, name, waypointIndex?)`: クリックされた待機点が経路上の
    どの訪問かを `resolveWaypointPathIndices` で解決し、`calculateArrivalTimeAtIndex`
    で自分の到達時刻を求める。
  - 1回目Sync時、アンカーに `pathIndex` を保存。
  - アンカー追従 useEffect: 保存した `pathIndex` が現在の経路上でも同じ地点を
    指す場合のみその訪問で再計算し、**経路構造が変わって食い違う場合は
    従来どおり node id の最初の出現にフォールバック**（安全側）。
- `components/create/WaypointPanel.tsx`: ⏱ ボタンが待機点の index を渡すように変更。

### 注意 / 残存リスク

- 相手キャラ側の到達時刻は従来どおり `indexOf`（最初の出現）基準のまま
  （影響範囲を抑えるため）。自分のアンカー安定化が主目的。
- `node_modules` 環境での型/ビルド検証は済だが、**実際の複雑Syncでの挙動は
  ブラウザ/Tauri で要確認**。具体的な再現手順（05/20 #1 の複雑例など）で
  最初のSyncの合流時刻が保たれるか確認すること。

## 症状2: 行動なしキャラ選択時に地点クリックをStartへ ✅

### 根本原因

`primaryIcon` 変更 useEffect が `suggestionTargetIndex` をリセットしていなかったため、
直前に別キャラのGoal等にフォーカスしていると `suggestionTargetIndex` が残留し、
行動未設定キャラを選んだ直後の地点クリックがStartではなく残留ターゲット（Goal等）に入っていた。

### 修正

`CreateView.tsx` の `primaryIcon` useEffect に `setSuggestionTargetIndex(null)` を追加。
ターゲット未指定時の `handleNodeClick` は「最初の空きスロット」を使うため、
これにより最初のクリックが Start（index 0）に入る。

## 症状8: 死亡設定モードの自動解除 ✅

### 根本原因

死亡設定モード `isSkullMode` が `Sidebar` のローカル state だったため、
マップ側（`CreateView`）のクリックから解除できなかった。

### 修正

- `store.ts`: `isSkullMode` / `setSkullMode` をグローバル state 化。
- `components/Sidebar.tsx`: ローカル `useState` を廃止しストアを参照。
- `components/CreateView.tsx`: `handleStageClick`（マップ背景）と
  `handleNodeClick`（ノード）の先頭で、`isSkullMode` 中なら `setSkullMode(false)`。
  サイドバーのアイコンクリック（死亡トグル本来の操作）は対象外。
