## #1 4ペインマップのズーム削除（`CreateView.tsx` / `common/MapElements.tsx`）
原因/方針: 4ペインは全フロアを俯瞰する用途なので、各ペインでのホイールズーム/ドラッグパンは不要。
- `FloorPane` から `useStageZoom`（ホイールズーム＋ドラッグ）を撤去。
- 代わりにマップ自然サイズをペインに**フィット（アスペクト比維持・中央寄せ）**するだけにした。
  - `MapImage` に `onLoad(w,h)` を追加し画像の自然サイズを通知。
  - `fitScale = min(paneW/mapW, paneH/mapH)`、`fitX/fitY` で中央寄せ。Stage は `draggable` 無効・`onWheel` 無し。

## #2 ノード不透明度（`create/MapObjectLayer.tsx`）
通常時のノード不透明度を `0.4 → 0.6`、経路ハイライト時の非経路ノードを `0.2 → 0.35` に引き上げて視認性を改善。

## #3 進行方向「>」マークの固定サイズ（`create/MapObjectLayer.tsx`）
原因: 矢印の翼をセグメントベクトルの **0.1 倍**で描いていたため、辺の長さに比例してサイズが変動していた（長い辺=大きい、短い辺=小さい）。
修正: 中点 M から**単位方向ベクトル** `u` と**固定長 `ARROW=9`（マップ論理座標）**で左右の翼を描くV字シェブロンに変更。辺の長さに依存せず一定サイズになる（`segLen > 30` の表示条件は維持）。

## #4 キャラ未選択時のSave Path（`CreateView.tsx`）
`handleSavePath`: 経路はあるがキャラ未選択(`selectedIcons` 空)の場合、早期 return せず **`CharacterSelectModal`（キャラアイコンのフローティングウィンドウ）を開く**。選択後 `handleCharSelect` / `handleMultiSelect` が当該キャラに経路を保存（`syncConstraints` も渡すよう統一、保存後 `setIsEditing(false)`）。

## #5 階段クリックのフロア切替廃止（`CreateView.tsx`）
`handleNodeClick` の階段ノード分岐 `onFloorChange(node.connectedFloor)`（グラフ編集時・経路作成時の両方）を撤去。4ペインで全フロアが同時に見えるため表示切替は不要。階段ノードは通常ノードと同様に「連結開始/経由地追加」として扱う。**経路計算（階段を介したフロア間の接続）は従来どおり**（`animationUtils` 等の計算ロジックは不変）。

## #6 サイドバー FLOOR セクション廃止（`Sidebar.tsx`）
4ペインで全フロア同時表示のため、ICONS の上にあった「FLOOR（2F/1F/B1）」切替を削除。未使用になった `activeFloor` / `onFloorChange`（destructure）も整理（プロップ型は親互換のため interface に残置）。
