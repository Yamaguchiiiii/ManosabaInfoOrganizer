## ✅ 実装済み

### #1 ナビゲーションガードの保存がキャラ選択を待たない（`CreateView.tsx`）
原因: ガードの「保存」分岐が `handleSavePath(); return true;` で、`handleSavePath` はキャラ未選択時に
モーダルを開くだけ（非同期）。`return true` で即遷移し、CreateView がアンマウントされてモーダルごと消え、保存されなかった。
修正: Promise ベースの `requestSaveOrPrompt()` を新設。キャラ選択済みなら即保存して `true`、未選択なら
モーダルを開き **選択完了=`true`（遷移可）／キャンセル=`false`（遷移中止）** を解決するまで待つ。
ガードは `if (choice === 'save') return await requestSaveOrPrompt();`。
モーダル側 `handleCharSelect`/`handleMultiSelect` は保存後に resolve(true)、`handleModalClose` は resolve(false)。

### #2 4ペインでの shift+LMB ペイン跨ぎ複数選択（`NoteView.tsx`）
編集モード(`isGridEditMode`)の `onSelect` で、別ペインのオブジェクトを shift+クリックした場合は
**currentペインを移さず**（移すと選択維持が崩れる）に `selectedIds` へトグル追加。`e.evt.stopPropagation()` で
ペイン→単一表示の切替も抑止。各ペインの Transformer は自ペインの選択ノードに個別アタッチするため、
ペインを跨いだ複数選択が同時表示される。
※ 4ペインでの選択/編集は編集モード(✏️)前提（通常の4ペイン表示はクリックで単一表示へ切替＝従来仕様）。

### #4 テキスト編集中のフレーム落ち（`NoteView.tsx`）
原因: 編集用 textarea の `onChange` が **1キーストロークごとに** `updateNoteObject`→store更新→
CanvasWorkspace の全オブジェクト再描画を起こしていた。
修正: 編集中の文字列を**ローカル state(`editingTextValue`)** で保持し、`onChange` はローカル更新のみ。
**blur 時にだけ** store へコミット（`updateNoteObject` + `saveNoteHistory`）。編集中は Konva テキストノードを
非表示にしている（textarea が前面）ため、ライブ再描画は不要でフレーム落ちが解消する。

### #5 Animate 4ペイン時のツールサイドバー消失（`NoteView.tsx`）
原因: compact のツールバーを `isSidePanels = compactMode && !isGridMode` の単一表示時のみ、各ペイン内の
左ストリップとして描画していたため、4ペイン(grid)では出なかった。
修正: ツールバーを**ペイン外の単一の左ストリップ**に移し、`compactMode` なら単一/4ペインの両方で常設。
ツールバー幅 `compactToolbarW`（単一: 3:2高さフィットの残り幅／4ペイン: 固定幅）を一度だけ計算し、
ペイン領域幅 `panesW = canvasSize.width - compactToolbarW` を各ペインのセルサイズ基準にした。
Stage はセル中央配置（旧 per-pane の toolbarW/paddingLeft ロジックは撤去）。

### #6 地点一覧の選択でターゲットが次へ移らない（`CreateView.tsx`）
原因: `handleSelectSuggestion` が `waypoints[suggestionTargetIndex]` を埋めるだけで、ターゲットを
次のボックスへ進めていなかった。連続クリックで同じボックスを上書きしていた。
修正: 入力後、**現在位置より後ろの最初の空ボックス**（無ければ全体の空ボックス）へ
`suggestionTargetIndex` を自動移動。空きが無ければ `null`（サイドバーを閉じる）。
