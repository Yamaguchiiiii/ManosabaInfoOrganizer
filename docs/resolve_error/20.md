## #1 Loading オーバーレイのフェードイン/アウト

### 現状
- `src/App.tsx`: `const [isTransitioning, setIsTransitioning] = useState(false);` と `{isTransitioning && <LoadingScreen overlay />}`（条件マウント＝瞬間切替）。
- `src/components/common/LoadingScreen.tsx`: transition なしの単純 div。

### 実装
**1. LoadingScreen.tsx** — props に `visible?: boolean`（default true）を追加し、マウント直後フェードインのための内部 state を持つ:
```tsx
export const LoadingScreen: React.FC<{ text?: string; overlay?: boolean; visible?: boolean }> = ({
    text = 'Loading ...', overlay = false, visible = true,
}) => {
    // マウント直後は opacity 0 で描画し、次フレームで 1 にしてフェードインさせる
    const [shown, setShown] = useState(false);
    useEffect(() => {
        const id = requestAnimationFrame(() => setShown(true));
        return () => cancelAnimationFrame(id);
    }, []);
    const opaque = shown && visible;
    return (
        <div style={{
            /* 既存スタイルはそのまま */
            opacity: opaque ? 1 : 0,
            transition: 'opacity 180ms ease',
            pointerEvents: opaque ? 'auto' : 'none',
        }}>…既存の中身…</div>
    );
};
```
※ `import React, { useState, useEffect } from 'react'` に変更。

**2. App.tsx** — `isTransitioning` を3状態に置換:
```tsx
type OverlayPhase = 'hidden' | 'visible' | 'leaving';
const [overlayPhase, setOverlayPhase] = useState<OverlayPhase>('hidden');
const FADE_MS = 200;            // LoadingScreen の 180ms + マージン
const MIN_OVERLAY_MS = 250;     // 既存値を踏襲

const handleTransition = (action: () => void) => {
    setOverlayPhase('visible');
    const shownAt = performance.now();
    requestAnimationFrame(() => {
        action();
        requestAnimationFrame(() => {
            const wait = Math.max(0, MIN_OVERLAY_MS - (performance.now() - shownAt));
            setTimeout(() => {
                setOverlayPhase('leaving');
                setTimeout(() => setOverlayPhase('hidden'), FADE_MS);
            }, wait);
        });
    });
};
```
JSX（`{isTransitioning && <LoadingScreen overlay />}` の箇所、モバイル/デスクトップ両方の `overlays` 内）:
```tsx
{overlayPhase !== 'hidden' && <LoadingScreen overlay visible={overlayPhase === 'visible'} />}
```
**3. 併せて実装**（revise №6）: `const transitionBusyRef = useRef(false);` を追加し、`changeModeWithTransition` / `changeFloorWithTransition` の先頭で `if (transitionBusyRef.current) return;` → handleTransition 開始で `true`、`setOverlayPhase('hidden')` と同時に `false`。連打での二重遷移とフェードの競合を同時に排除する。

### 受入
- 遷移時にオーバーレイが 180ms でフェードイン、処理完了後フェードアウト。
- NavRail/下タブを高速連打しても遷移1回・点滅なし。
- 初期ロード画面（`!_hasHydrated` の `<LoadingScreen />`）は従来どおり（変更不要。`visible` default true でフェードインだけ付く）。

## #2 PNG書き出しの範囲選択（4ペイン全体 / 現在ペイン）

### 現状
- `NoteView.tsx` `handleExportPng`（grep: `const handleExportPng`）は `stageRefs.current[currentCanvasIndex]` のみ出力。
- **制約**: 単一表示時は現在ペインの Stage しかマウントされない（grep: `if (!isGridMode && currentCanvasIndex !== index) return null;`）。よって「全体」は 4ペイン表示中のみ提供する。

### 実装（すべて `CanvasWorkspace` 内）
**1. showDialog の購読を追加**（既存 selector 群の並びに）:
```ts
const showDialog = useAppStore(state => state.showDialog);
```
**2. dataURL 化の共通ヘルパを抽出**（現 handleExportPng の中身を関数化）:
```ts
// 1ペインを「選択枠なし」で dataURL 化する（紙面背景はまだ乗せない）
const capturePane = (index: number): string | null => {
    const stage = stageRefs.current[index];
    const layer = stage?.getLayers()[0];
    if (!stage || !layer) return null;
    const s = layer.scaleX() || 1;
    const excluded = stage.find('.__export_exclude');
    excluded.forEach(n => n.visible(false));
    layer.batchDraw();
    try {
        return targetType === 'preset'
            ? stage.toDataURL({ pixelRatio: 2 / s, mimeType: 'image/png' })   // 常に 2400×1600
            : stage.toDataURL({ pixelRatio: 2, mimeType: 'image/png' });      // 表示実寸の2倍
    } finally {
        excluded.forEach(n => n.visible(true));
        layer.batchDraw();
    }
};

// dataURL(透明背景) → 紙面色を敷いた canvas に載せ替え（既存 #B-4 のパターンを流用）
const loadImage = (url: string) => new Promise<HTMLImageElement>((res, rej) => {
    const i = new Image(); i.onload = () => res(i); i.onerror = rej; i.src = url;
});
```
**3. handleExportPng を async 化して分岐**:
```ts
const handleExportPng = useCallback(async () => {
    let mode: 'current' | 'all' = 'current';
    if (isGridMode) {
        const v = await showDialog({
            title: 'PNG書き出し',
            message: '書き出す範囲を選んでください。',
            buttons: [
                { label: '4ペイン全体', value: 'all', variant: 'primary' },
                { label: '現在のペイン', value: 'current' },
                { label: 'キャンセル', value: 'cancel' },
            ],
        });
        if (v !== 'all' && v !== 'current') return;   // '' = ESC/差し替え も中止
        mode = v;
    }
    try {
        if (mode === 'current') {
            const url = capturePane(currentCanvasIndex);
            if (!url) return;
            const img = await loadImage(url);
            const c = document.createElement('canvas');
            c.width = img.naturalWidth; c.height = img.naturalHeight;
            const ctx = c.getContext('2d')!;
            ctx.fillStyle = '#ECD2B3'; ctx.fillRect(0, 0, c.width, c.height);
            ctx.drawImage(img, 0, 0);
            downloadDataUrl(c.toDataURL('image/png'), `manosaba-note-${targetType}-${Date.now()}.png`);
        } else {
            const urls = [0, 1, 2, 3].map(capturePane);
            if (urls.some(u => !u)) { toast.error('ペインの取得に失敗しました'); return; }
            const imgs = await Promise.all((urls as string[]).map(loadImage));
            // グリッド中は4ペインのセル寸が同一 → 出力も同一サイズ
            const w = imgs[0].naturalWidth, h = imgs[0].naturalHeight, GAP = 8;
            const c = document.createElement('canvas');
            c.width = w * 2 + GAP; c.height = h * 2 + GAP;
            const ctx = c.getContext('2d')!;
            ctx.fillStyle = '#444'; ctx.fillRect(0, 0, c.width, c.height);      // 区切り線
            imgs.forEach((img, i) => {
                const col = i % 2, row = Math.floor(i / 2);
                const x = col * (w + GAP), y = row * (h + GAP);
                ctx.fillStyle = '#ECD2B3'; ctx.fillRect(x, y, w, h);
                ctx.drawImage(img, x, y);
            });
            downloadDataUrl(c.toDataURL('image/png'), `manosaba-note-${targetType}-all-${Date.now()}.png`);
        }
        toast.success('PNGを書き出しました');
    } catch {
        toast.error('PNG書き出しに失敗しました');
    }
}, [isGridMode, currentCanvasIndex, targetType, showDialog]);
```
※ 既存の `img.onload` コールバック方式は上記 `loadImage`/await に置き換え（コード量削減。挙動同等）。
※ ボタンの `onClick={handleExportPng}` は async でもそのまま動く（2箇所: compact「📷 PNG」/ サイドバー「📷 PNG書き出し」）。

### 受入
- 4ペイン表示 → 📷 → ダイアログ →「4ペイン全体」で 2x2 合成PNG（preset なら約 4808×3208、区切り線つき、選択枠なし）。
- 「現在のペイン」/ 単一表示では従来同等。ESC で中止してもキャンバス状態が壊れない（excluded の visible 復帰を capturePane 内 finally で担保）。

## #5 経路 floating window（WaypointPanel）がマップに被る

### 原因
`src/components/create/WaypointPanel.tsx` のルート div が `position:absolute; bottom:30px; right:30px; maxWidth:300px` の固定フローティング（grep: `bottom: '30px', right: '30px'`）。モバイル（単一ペイン）と 4x1（縦1列）ではペイン幅=画面幅のため必ず被る。

### 実装
**1. useResponsiveQuadGrid を拡張**（`src/hooks/useResponsiveQuadGrid.ts`）— 戻り値をオブジェクトに:
```ts
export interface QuadGridResult { gridStyle: QuadGridStyle; isSingleColumn: boolean; }
// setStyle と同時に判定を保持:
return { gridStyle: style, isSingleColumn: style.gridTemplateColumns === '1fr' };
```
呼び出し2箇所を更新: `CreateView.tsx`（grep: `useResponsiveQuadGrid(gridRef)`）と `AnimateView.tsx`。`const { gridStyle, isSingleColumn } = useResponsiveQuadGrid(gridRef);` とし、既存の `style={{ …gridStyle }}` 適用はそのまま。

**2. WaypointPanel に variant と折りたたみを追加**:
```ts
interface WaypointPanelProps { …既存…; variant?: 'floating' | 'bottom'; }
```
コンポーネント内:
```tsx
const [collapsed, setCollapsed] = useState(variant === 'bottom');  // bottom は既定折りたたみ
```
ルート div の style を分岐:
```ts
const rootStyle: React.CSSProperties = variant === 'bottom'
  ? { position: 'absolute', left: 8, right: 8, bottom: 8, maxWidth: 'none',
      maxHeight: collapsed ? undefined : '45vh', overflowY: 'auto', /* 残りは既存と同じ背景/枠 */ }
  : { /* 既存の floating スタイルそのまま */ };
```
既存 JSX の最上部に**ヘッダ行**を追加（floating でも表示してよい＝常設の折りたたみ機能になる）:
```tsx
<div style={{ display: 'flex', alignItems: 'center', gap: 8, width: '100%' }}>
  <button onClick={() => setCollapsed(v => !v)} style={…小ボタン…}>{collapsed ? '▸' : '▾'}</button>
  <span style={{ fontSize: '0.8rem', color: '#ccc', flex: 1 }}>
    経路 {waypoints.filter(w => w.id).length}地点{syncConstraints.length > 0 && ` / sync ${syncConstraints.length}`}
  </span>
</div>
```
折りたたみ時は「開始条件・地点リスト・sync一覧」（`(!savedPathData || isEditing) && (…)` ブロック）を隠し、**下段の Save/Edit/Delete 行は常時表示**（`savedPathData && !isEditing ? … : …` の既存2ブロックはそのまま）。実装は該当ブロックを `{!collapsed && (…既存詳細…)}` で包むだけ。

**3. CreateView から variant を渡す**:
```tsx
<WaypointPanel …既存props… variant={isMobile || isSingleColumn ? 'bottom' : 'floating'} />
```

### 受入
- モバイル/4x1（ウィンドウを縦長にして再現）で、パネルが下部の細いバー（~44px）になり、マップ全域をタップできる。展開時も maxHeight 45vh で上部のマップが見える。

## #7 キャラノート: ハンバーガーからキャラ選択

### 原因
- headerBar が15アイコン横スクロール（M1 簡易実装）。
- `actualCharIndex` が `NoteView` ローカル state（grep: `const [actualCharIndex, setActualCharIndex] = useState(0)`）のため、`MobileContextSheet`（☰）から操作できない。

### 実装（state 移管を含むため単独コミット）
**1. store.ts** — AppState へ追加（persist 対象のままで良い＝前回開いていたキャラを記憶）:
```ts
// キャラクターノートで開いているキャラ（ICON_FILES の index）。#07/04-7
noteCharIndex: number; setNoteCharIndex: (i: number) => void;
// 実装:
noteCharIndex: 0, setNoteCharIndex: (i) => set({ noteCharIndex: i }),
```
**2. NoteView.tsx** — `actualCharIndex` を store 化:
- `const [actualCharIndex, setActualCharIndex] = useState(0);` を削除し、
  `const actualCharIndex = useAppStore(state => state.noteCharIndex);` と

## #9 用語再定義（同室=会話 / syncすれ違い=遭遇）+ 遭遇ジャンプ

### 9-1. タイミング一元化ユーティリティ（新規 `src/utils/presetTiming.ts`）
> revise_bad_implementation.md №14 の解でもある。`AnimationTimeline` と `useAnimationPositions` の offset 重複を排除する。
```ts
import { MapNode } from '../store';
import { resolveStartTimes, normalizeTimelineData, precomputePath, computeAnchors } from './animationUtils';

export interface PresetTiming {
    offset: number;                          // 全キャラ最小開始時刻（これを 0 に正規化）
    maxDuration: number;                     // 正規化後の全体尺
    resolvedStarts: Record<string, number>;  // 絶対時刻（正規化前）
}

export const computePresetTiming = (rawData: Record<string, unknown>, nodes: MapNode[]): PresetTiming => {
    const resolvedStarts = resolveStartTimes(rawData, nodes);
    const spans: { start: number; end: number }[] = [];
    Object.entries(rawData).forEach(([id, raw]) => {
        const base = normalizeTimelineData(raw);
        if (!base) return;
        const charData = { ...base, startTime: resolvedStarts[id] ?? base.startTime ?? 0 };
        const cached = precomputePath(charData.path, nodes);
        const anchors = computeAnchors(charData, cached);
        if (anchors.length === 0) return;
        spans.push({ start: anchors[0].time, end: anchors[anchors.length - 1].time });
    });
    if (spans.length === 0) return { offset: 0, maxDuration: 300, resolvedStarts };
    const minStart = Math.min(...spans.map(s => s.start));
    const offset = (Number.isFinite(minStart) && minStart > 0) ? minStart : 0;
    const max = Math.max(...spans.map(s => s.end - offset));
    return { offset, maxDuration: Math.max(max + 60, 300), resolvedStarts };
};
```
テスト `src/utils/__tests__/presetTiming.test.ts`: ①全員 start=0 → offset 0 ②全員 start≥100 → offset=最小値・尺が縮む ③空データ → {0, 300}。

### 9-3. イベント統合フック（新規 `src/hooks/usePresetEvents.ts`）
```ts
import { useMemo } from 'react';
import { useAppStore } from '../store';
import { computePresetTiming } from '../utils/presetTiming';
import { detectEncounters } from '../utils/encounterDetection';
import { normalizeTimelineData } from '../utils/animationUtils';

export interface TimedEvent {
    kind: 'talk' | 'auto-talk' | 'pass';   // 💬明示会話 / 💬同室検出 / ⚇遭遇(syncすれ違い)
    label: string;                          // 地点名
    charIds: string[];
    t: number;                              // 正規化済みフレーム（ジャンプ先）
    tEnd?: number;                          // auto-talk の帯表示用
}

export const usePresetEvents = (): { maxDuration: number; offset: number; events: TimedEvent[] } => {
    const presets = useAppStore(s => s.presets);
    const activePresetId = useAppStore(s => s.activePresetId);
    const nodes = useAppStore(s => s.nodes);
    const activePreset = presets.find(p => p.id === activePresetId);

    return useMemo(() => {
        if (!activePreset?.data) return { maxDuration: 300, offset: 0, events: [] };
        const { offset, maxDuration, resolvedStarts } = computePresetTiming(activePreset.data, nodes);
        const events: TimedEvent[] = [];

        // ⚇ 遭遇: 各キャラの syncConstraints（すれ違い/合流の瞬間）
        const seen = new Set<string>();   // 相互syncの重複除去
        Object.entries(activePreset.data).forEach(([id, raw]) => {
            const base = normalizeTimelineData(raw);
            (base?.syncConstraints || []).forEach(sc => {
                const chars = [id, ...sc.charIds];
                const key = `${Math.round(sc.meetingTime)}:${sc.waypointId}:${[...chars].sort().join(',')}`;
                if (seen.has(key)) return;
                seen.add(key);
                events.push({ kind: 'pass', label: sc.waypointName, charIds: chars, t: sc.meetingTime - offset });
            });
        });
        // 💬 会話（同室の自動検出）
        detectEncounters(activePreset.data, nodes, resolvedStarts).forEach(e =>
            events.push({ kind: 'auto-talk', label: e.nodeName, charIds: e.charIds, t: e.start - offset, tEnd: e.end - offset }));
        // 💬 会話（明示・#8）
        (activePreset.events || []).forEach(ev =>
            events.push({ kind: 'talk', label: ev.nodeName, charIds: ev.charIds, t: ev.time - offset }));

        return {
            maxDuration, offset,
            events: events.filter(e => (e.tEnd ?? e.t) >= 0 && e.t <= maxDuration).sort((a, b) => a.t - b.t),
        };
    }, [activePreset, nodes]);
};
```
