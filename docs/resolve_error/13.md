## #4 ホバー枠の抑制（編集モード時）✅
`NoteView.tsx` のペイン枠 `border`/`boxShadow` を `isHovered && !isGridEditMode` 条件に。
編集モード中はホバーの青枠/グローを出さない（ペイン選択モードのときのみ表示）。

## #5 ノート子要素名 ✅
`Sidebar.tsx`: 統括→**全体ノート** / 事件ノート（既存）/ キャラクター→**キャラクターノート** / 雑多→**メモ**。

## #6 カラーピッカーの激重＋OOM ✅
原因は2つ:
1. **OOM**: `updateNoteObject` が `useAppStore.setState`→persist で巨大stateを毎回 IndexedDB に書く
   （= 3-1b と同根）。→ store の persist debounce（commit `2285431`）で解消済み。
2. **激重**: カラーピッカーの `onChange` が連続発火し、毎回 `setShapeContextMenu`＋`updateNoteObject`
   →キャンバス全再描画（オブジェクトのコールバックが毎レンダ再生成でmemo無効）。
   → 連続入力のコミットを間引く `commitThrottled`（先頭即時＋末尾100ms）を新設し、
   Line Color / Line Width / Fill Color に適用（`NoteView.tsx`）。ネイティブpiピッカーの
   ダイアログは即時、ページ側の反映のみ間引き。

## #7 ドラッグ選択の無効化 ✅
`NoteView.scss`: `.char-sidebar` / `.char-topbar` / `.preset-header` に `user-select: none`。
（メインの `.sidebar` / `.top-bar` は既に none）

## #8 画像はクリックのみ配置（比維持）✅
`NoteView.tsx`: 画像を `handleStageMouseDown` で**即時配置**（`getImageSizeFromUrl` で
アスペクト比維持の表示サイズを算出）。ドラッグサイズ指定の分岐（`rect/circle/triangle/image`）
から `image` を除外。図形（矩形/円/三角）はドラッグサイズ指定を維持。

## #9 Delete ボタン ✅
`create/WaypointPanel.tsx`: Save Path の横に赤い Delete ボタンを追加（`handleDeletePath`）。

## ⏸ #2 Animate 右下に事件ノートCanvas（要方針確認）
過去の `_symptoms 06/20 22:46 #7`「AnimateのTimelineNote(canvas)を消してcanvas領域を広げたい」
で **NotesPanel を撤去**し、`最優先A` で右下セルを**操作盤(AnimationTimeline)で充填**した経緯がある。
今回「右下に事件ノートCanvasを出す」はこれと**逆方向**。実装は可能（`NotesPanel` 残存、
`usePlaybackStore`化でAnimateView再レンダも安全）だが、**操作盤と事件ノートCanvasをどう同居させるか**
（上下分割／タブ切替／操作盤を別位置へ）が設計判断のため、方針を確認してから実装する。

## ⏸ #3 ズームでCanvasサイズが変わる（要再現情報）
Note Canvas は論理サイズ 1200×800 固定＋`scale=min(stageW/1200, stageH/800, 1)` で
コンテナにフィットさせている。**ブラウザzoom**するとコンテナのCSSピクセル実寸が変わり
`scale` が変化＝見かけサイズが変わる（responsive な設計上の帰結）。
「サイズを変えない」を厳密に実現するにはブラウザzoom量の打ち消しが必要で手段が限られる。
- 確認したい: ①ブラウザの Ctrl+/− か、②アプリ内のズーム操作か、③ピンチか。
  ②③なら該当処理を特定して固定化できる。①なら許容仕様/対処方針を相談したい。
