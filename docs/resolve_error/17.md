## #1 跨ぎドラッグの座標がおかしい（`NoteView.tsx handleObjectDragEnd`）
### 原因
事件ノート(preset)の範囲クランプ `[0,1200]×[0,800]` を、跨ぎ移動の計算より**前に**ソース座標
`localX = clamp(e.target.x())` へ適用していた。隣のペインへドラッグすると `e.target.x()` はソース範囲外
（例: 右隣へ → 1200超）になり、クランプで 1200 等に丸められてから跨ぎオフセットを足すため、
移動先の**端へ飛ぶ／ドロップ位置とずれる**（症状の「たまにペインの端に配置」と一致）。

### 修正
1. ドラッグ後の**生の論理座標 `rawX/rawY`（クランプ前）**で計算する。
2. 跨ぎ移動は **Stage コンテナの画面矩形 + Layer の scale/offset** を使い、ドロップされたオブジェクト原点の
   画面座標 → 移動先 Layer の論理座標へ正確に変換（ペインのレターボックス中央寄せやツールバー帯にも追従）。
   ```
   screenX = srcBox.left + rawX * sLayer.scaleX() + sLayer.x()
   newX    = (screenX - tgtBox.left - tLayer.x()) / tLayer.scaleX()
   ```
3. クランプは**最終座標 `newX/newY` に対してのみ**適用。
4. 移動対象セットはソースペインのオブジェクトに限定（別ペインのドラッグでも正しく対象を取得）。

## #2 4ペイン編集での跨ぎ shift 選択ができない（`NoteView.tsx`）
### 原因
選択枠を描く **Transformer が `isCurrent`（現在ペイン）でのみレンダリング**されていた。別ペインの
オブジェクトを shift+クリックすると `selectedIds` には追加されても、そのペインには Transformer が無いため
**選択が見えず・`trRefs` も未設定**で、跨ぎ選択が機能していないように見えた（ユーザー指摘の「現在選択ペイン判定が阻害」）。

### 修正
4ペイン編集中（`isGridMode && isGridEditMode`）は **全ペインに Transformer を出す**
（`(isCurrent || (isGridMode && isGridEditMode))`）。各ペインの Transformer が自ペインの選択ノードへ
個別アタッチし、ペインを跨いだ複数選択が同時に可視化される。
（14:10-#2 の onSelect 側で「shift 時は current ペインを移さない」変更済みと併せて、跨ぎ shift 選択が成立する。）
