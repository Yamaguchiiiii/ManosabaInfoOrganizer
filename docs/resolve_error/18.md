## #3 テキスト編集後に枠外クリックで入力が戻る（`NoteView.tsx`）
### 原因
テキスト編集中に Canvas をクリックして抜けると、入力が編集前に戻っていた。
編集用 textarea は「**blur 時に store へコミット**」する実装だが、Canvas クリック時のイベント順序は
**mousedown → （フォーカス移動で）blur**。Stage の `handleStageMouseDown`（空白クリック分岐）が **mousedown で
`setEditingTextId(null)` を実行して textarea をアンマウント**するため、その後の `onBlur`（コミット）が走らず、
入力が破棄され `obj.text`（編集前）に戻っていた。

### 修正
編集終了の経路を一本化する `finishTextEditing()` を新設:
- 入力値を `editingTextValueRef`、編集対象IDを `editingTextIdRef` にミラー。
- `finishTextEditing()` は ref から確実にコミット（`updateNoteObject`＋`saveNoteHistory`）してから `editingTextId` を解除。
  ID refを即 null 化し、mousedown と blur の両方から呼ばれても**二重コミットしない（冪等）**。
- 呼び出し元: textarea の `onBlur` / `handleStageMouseDown`（クリア前にコミット）/ Enter / Escape。
これで blur が走らない経路（クリックでアンマウント）でも入力が必ず保存される。

## #4 Enterで確定・Shift+Enterで改行（`NoteView.tsx`）
textarea の `onKeyDown`:
- `Enter`（Shiftなし）→ `preventDefault()` ＋ `finishTextEditing()`（確定）。
- `Shift+Enter` → 既定動作（改行）。
- `Escape` → `finishTextEditing()`（確定して閉じる）。
